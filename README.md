# QUIERO

Сайт небольшой кондитерской в Алматы (ул. Гоголя 167, Алмалинский район). Клиент выбирает торт, кладёт его в корзину, оформляет заказ на дату с доставкой или самовывозом и следит за статусом. Для индивидуальных тортов есть страница с кнопкой «Обсудить с кондитером в WhatsApp».

Дипломный проект.

## Роли

| Роль | Что может |
|---|---|
| Гость | Смотреть каталог, карточки сладостей, условия доставки, собирать корзину |
| Клиент | Оформлять заказы и видеть свои заказы со статусами |
| Администратор | Управлять сладостями и их вариантами, видеть все заказы и менять их статус |

## Стек

- Клиент: React (Vite)
- Сервер: Node.js + Express
- База данных: PostgreSQL
- ORM (работа с базой через код): Prisma
